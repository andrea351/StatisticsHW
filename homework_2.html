The same message is encrypted two ways: with EC ElGamal on secp256k1, built on the scalar multiplication of homework 1, and with the Caesar shift cipher. Each is then broken — the Caesar cipher by letter statistics, the toy EC scheme by searching its deliberately small key space — and the two attacks are compared.

0The message and the keys

Type a message to follow through both systems. The EC private key is restricted to a small range on purpose, exactly the weakness that section 5 attacks; the Caesar key is a shift from 0 to 25.

1Toy public-key scheme: EC ElGamal on secp256k1

This reuses Q = kG from homework 1. The curve and its arithmetic are real; only the private key is kept small. Encryption works one byte at a time with three ideas: map the byte to a curve point, blind it with a random multiple of the public key, and send a hint that only the private key can undo.

Encryption, step by step

Ciphertext and decryption

The role of each key

d — private key

A secret number in 1…2^b. Only d can strip the blinding factor, because computing it needs d·C₁. Whoever knows d can read every message and could sign as the owner.

Q = dG — public key

Published freely. Anyone can encrypt to the owner with it, but recovering d from Q is the elliptic-curve discrete logarithm problem.

r — ephemeral key

A fresh random number for every byte. It makes the scheme randomized: the same letter encrypts to a different pair each time. Reusing r would leak the relationship between messages.

2Classical symmetric scheme: the Caesar cipher

Each letter is shifted forward by the key k and wrapped around the alphabet; decryption shifts back by the same k. The key is shared secretly in advance, and the very same value both encrypts and decrypts, so this is a symmetric cipher.

3Comparison of the two schemes

Statistical fingerprint

The clearest difference is visible in the output. The Caesar cipher only relabels letters, so the plaintext's letter distribution survives, merely rotated. The EC scheme's output is spread uniformly, because every byte is blinded by a random curve point.

4Statistical cryptanalysis of the Caesar cipher

The attacker knows the language but not the key. Because the cipher preserves letter frequencies, the key can be read off the statistics instead of the content. Three methods are compared, all exploiting the known distribution of English letters.

Recovering the key of the current ciphertext

Effectiveness versus ciphertext length

Short texts do not contain enough letters for their statistics to settle, so every method fails below some length. This experiment encrypts many random passages of each length with a random key and measures how often each method recovers it.

5Breaking the toy EC scheme: attacking the restricted key space

The EC ciphertext carries no usable statistics, so a frequency attack is hopeless. The only weakness is that d was drawn from a small range, so the attacker can search it directly from the public key Q. Two searches are compared: trying every candidate, and the baby-step giant-step shortcut.
